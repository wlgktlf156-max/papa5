작품 사진을 넣는 폴더입니다.

· 파일 이름을 작품 id 와 같게 저장하세요.  예) id 가 a01 이면  a01.jpg / a01.webp / a01.png
· 사진을 넣은 뒤 works.json 의 그 작품 줄에 "image": "a01.jpg" 처럼 파일 이름을 적고
  사이트를 새로고침하면 그 액자에 사진이 걸립니다.
  ("image": "auto" 라고 적으면 works/ 에서 id 와 같은 이름을 자동으로 찾습니다)
· 권장 규격: 긴 변 1600px, WebP 또는 JPG, 파일 하나에 200~350KB
· 사진이 없으면 지금처럼 임시 이미지가 걸립니다.

자세한 순서는 사이트 폴더의 README.md 「작품 추가하는 법」을 보세요.
